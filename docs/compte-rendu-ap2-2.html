AP2.2 — Compte rendu Windows Server et DHCP

Travaux documentés : adressage IPv4 fixe, installation du rôle DHCP, étendues par sous-réseau et réservation d'adresse sur un poste client.

Windows Server 2022PowerShellDHCPVLSM /27

Les opérations ci-dessous correspondent aux preuves décrites dans le compte rendu fourni. Ce document traite principalement de DHCP et du réseau ; il ne présente pas encore la mise en place complète du domaine Active Directory et des GPO prévue dans le sujet AP2.2.

1. Configuration initiale du serveur

Installation de Windows Server en mode sans interface graphique, puis configuration de l'interface réseau via sconfig. Le compte rendu décrit un serveur nommé SRV et les paramètres de l'environnement d'essai suivants :

ParamètreValeur de test
Adresse IP192.168.20.2
Passerelle192.168.20.1
DNS configuré8.8.8.8
Nom d'hôteSRV

2. Installation et vérification du service DHCP

Le rôle DHCP a été installé via PowerShell, puis le service démarré et contrôlé :

Install-WindowsFeature DHCP -IncludeManagementTools
Start-Service DHCPServer
Get-Service DHCPServer

La commande de vérification renvoie l'état Running, indiquant que le service est démarré. Le premier essai montre une étendue nommée CURLING, créée avec Add-DhcpServerv4Scope et vérifiée avec Get-DhcpServerv4Scope.

Add-DhcpServerv4Scope
Get-DhcpServerv4Scope

Le compte rendu indique une plage attendue de 192.168.20.10 à 192.168.20.100, tandis qu'une capture affiche une plage effective se terminant à 192.168.20.120. Cette différence reste à vérifier.

4. Tests réseau et pare-feu

Un poste client n'arrivait initialement pas à joindre le serveur par ping. Le compte rendu montre l'ajout d'une règle du pare-feu Windows autorisant les requêtes ICMPv4 entrantes, suivi d'un ping réussi vers le serveur.

Ces tests permettent de vérifier la connectivité entre le client et le serveur de laboratoire, sans constituer à eux seuls une validation de tous les services réseau.

5. Réservation DHCP pour un client

Une réservation a été réalisée à partir de l'adresse physique du poste client, au moyen de Add-DhcpServerv4Reservation, puis contrôlée avec Get-DhcpServerv4Reservation. Le poste apparaît avec l'adresse fixe 172.16.1.8 et le masque 255.255.255.224.

Add-DhcpServerv4Reservation
Get-DhcpServerv4Reservation -ScopeId 172.16.1.0

La preuve d'origine inclut l'identifiant matériel de l'ordinateur ; celui-ci n'est pas reproduit ici pour limiter la diffusion d'informations relatives au poste.

6. Points de recettage mentionnés

  • Adressage IPv4 fixe du serveur.
  • Étendue DHCP par VLAN ou sous-réseau.
  • État de fonctionnement du service DHCP.
  • Réservation IP selon l'adresse MAC du client.
  • Agent relais DHCP (mentionné au recettage ; preuve détaillée non fournie ici).
  • Outil de scan réseau pour récupérer des adresses MAC (mentionné au recettage).
  • Documentation technique.
